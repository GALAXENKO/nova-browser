# Nova Browser 1.0.0

Первый публичный релиз браузера **Nova Browser** для Windows и Android.

## Что внутри

### Windows (x64)

- Браузер на движке **Microsoft Edge WebView2 (Chromium)**.
- Множественные вкладки, восстановление сессии, закрытие средней кнопкой.
- Адресная строка с подсказками и поиском.
- Закладки, история посещений, менеджер загрузок.
- Приватное окно без записи истории.
- Поиск по странице, масштабирование, домашняя страница.
- Светлая, тёмная и системная темы.
- Русский интерфейс.

### Android (6.0+)

- Браузер на системном **Android WebView (Chromium)**.
- Вкладки, адресная строка, навигация назад/вперёд/обновить/домой.
- Встроенная стартовая страница с поиском, закладками и быстрыми ссылками.
- Закладки, история, загрузки файлов.
- Поиск по странице с подсветкой.
- Светлая, тёмная и системная темы, интерфейс под экран телефона.
- Открытие ссылок `http/https` из других приложений.

## Установка

**Windows.** Запустите `NovaBrowser-Setup-1.0.0.exe` либо просто откройте
`NovaBrowser-1.0.0-portable.exe`. Файлы не подписаны сертификатом разработчика, поэтому SmartScreen
может показать предупреждение — «Подробнее» → «Выполнить в любом случае».
Для Windows 10 может потребоваться Microsoft Edge WebView2 Runtime (установщик
предложит скачать его).

**Android.** Скопируйте `NovaBrowser-1.0.0.apk` на телефон, разрешите установку из
неизвестных источников и откройте файл. APK подписан самостоятельно (self-signed),
поэтому Play Protect может попросить подтвердить установку.

## Известные ограничения

- Нет автообновления: новые версии нужно скачивать вручную из Releases.
- На Android используется системный WebView — некоторые сайты с защитой от ботов,
  DRM-видео и банковские приложения могут работать некорректно.
- На Windows часть сайтов может не поддерживаться компонентом WebView2.
- Расширения браузера не поддерживаются.

## Технические детали

- Windows: .NET 8, WPF, WebView2 1.0.4314.35, single-file self-contained, `win-x64`.
- Android: `com.novabrowser.mobile`, versionCode 1, minSdk 23, targetSdk 34,
