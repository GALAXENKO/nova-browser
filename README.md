# Nova Browser

**Nova Browser** — быстрый браузер на движке Chromium для Windows и Android.
Один проект, две платформы: настольное приложение на WPF + Microsoft Edge WebView2
и мобильное приложение на нативном Android WebView.

> Nova Browser — самостоятельный продукт. Он **не является** Google Chrome,
> не связан с Google LLC, Microsoft Corporation и не одобрен ими.

## Возможности

### Windows (ПК)

| | |
|---|---|
| Движок | Microsoft Edge WebView2 (Chromium) |
| Вкладки | Множественные вкладки, перетаскивание, закрытие средней кнопкой, восстановление сессии |
| Навигация | Адресная строка с подсказками, поиск, кнопки назад/вперёд/обновить/домой |
| Закладки | Панель закладок, добавление и удаление |
| История | Полная история посещений с поиском и очисткой |
| Загрузки | Список загрузок с прогрессом и открытием файлов |
| Приватный режим | Отдельное окно без записи истории, временный профиль |
| Поиск по странице | Встроенная панель поиска |
| Масштаб | Изменение масштаба страницы |
| Настройки | Домашняя страница, поисковая система, тема (светлая/тёмная/системная) |
| Тема | Светлая и тёмная темы, собственные иконки |
| Язык интерфейса | Русский |

### Android (телефон)

| | |
|---|---|
| Движок | Системный Android WebView (Chromium) |
| Вкладки | Несколько вкладок с переключением и закрытием |
| Навигация | Адресная строка, кнопки назад/вперёд/обновить/домой |
| Стартовая страница | Встроенная страница с поиском, закладками и быстрыми ссылками |
| Закладки | Добавление, удаление, переход |
| История | Список посещений с очисткой |
| Загрузки | Скачивание файлов через системный менеджер загрузок |
| Поиск по странице | Поиск с подсветкой совпадений |
| Настройки | Домашняя страница, поисковая система, тема (светлая/тёмная/системная) |
| Тема | Тёмная и светлая темы, адаптация под экран телефона |
| Внешние ссылки | Открытие ссылок `http/https` из других приложений |

## Установка

### Windows

**Установщик**

1. Скачайте `NovaBrowser-Setup-1.0.0.exe`.
2. Запустите и следуйте шагам мастера.
3. Если Windows SmartScreen показывает предупреждение: «Подробнее» → «Выполнить в любом случае»
   (файл не подписан сертификатом разработчика).

**Портативная версия**

1. Скачайте `NovaBrowser-1.0.0-portable.exe` в любую папку.
2. Запустите — установка не требуется.

Для работы нужен компонент **Microsoft Edge WebView2 Runtime**. В Windows 11 он уже
установлен; в Windows 10 установщик предлагает скачать его автоматически.

### Android

1. Скачайте `NovaBrowser-1.0.0.apk` на телефон.
2. Разрешите установку из неизвестных источников для файлового менеджера или браузера.
3. Откройте APK и подтвердите установку.
4. Если Play Protect предупреждает — «Всё равно установить» (APK подписан самостоятельно).

**Требования:** Android 6.0 (API 23) и выше, любая архитектура (WebView системный).

## Сборка из исходников

### Windows

```powershell
dotnet publish NovaBrowser\NovaBrowser.csproj -c Release -r win-x64 --self-contained true -o publish
```

Установщик (нужен [NSIS](https://nsis.sourceforge.io/)):

```powershell
makensis installer\NovaBrowser.nsi
```

### Android

Сборка без Gradle — напрямую инструментами Android SDK:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File NovaMobile\build-apk.ps1
```

Скрипт выполняет: `aapt2 compile` → `aapt2 link` → `javac` → `d8` → упаковка →
`zipalign` → `apksigner`. Требуется JDK 17 и Android SDK Build-Tools 35.0.0.

## Структура репозитория

```
NovaBrowser/          Приложение для Windows (WPF, .NET 8, WebView2)
  Assets/             Иконки и встроенная стартовая страница
  Models/             Модели: вкладки, закладки, история, загрузки, настройки
  Services/           Данные, темы, навигация, логирование
  Converters/         Конвертеры WPF
installer/            Скрипт установщика NSIS и его ресурсы
NovaMobile/           Приложение для Android (Java, WebView)
  src/                Исходный код
  res/                Ресурсы, темы, иконки
  assets/             Стартовая страница newtab.html
  build-apk.ps1       Сборка APK без Gradle
```

## Конфиденциальность

История, закладки, настройки, кэш и данные сайтов хранятся **локально** на устройстве.
Разработчик не получает историю посещений. Посещаемые сайты и поисковые системы
обрабатывают данные по своим политикам.
